# Stats Watch

Public downloads for Stats Watch, a macOS system-monitoring fork of
[Stats](https://github.com/exelban/stats).

Download the latest signed and notarized build from
[Releases](https://github.com/emptystring-dev/statswatch/releases). Automatic
updates are not enabled; download new versions manually.

Stats Watch is not an official Stats release and is not affiliated with its
maintainers. The fork retains Stats' MIT license and upstream attribution.
